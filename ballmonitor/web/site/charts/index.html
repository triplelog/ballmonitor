How this works

Each input box takes a formula using season stats like HR, AB, or BB. MathZetta formats your formula as math, and Python draws the chart right inside your browser. The first chart takes a few seconds to download Python (and uses a noticeable chunk of mobile data, though it's cached afterward). Nothing you type leaves your device.

Data from the Lahman Baseball Database (SABR, CC BY-SA 3.0), covering hitters with 400+ at-bats and pitchers with 100+ innings in a season.
