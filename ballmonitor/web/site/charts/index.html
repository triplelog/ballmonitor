How this works

Each box is a formula over a season's numbers (HR, AB, BB…). What you type is read by MathZetta, shown as math, and the chart is drawn by a short Python program right in your browser. The first chart downloads Python into your browser (a few seconds, and a sizeable download on a phone plan; afterwards it's cached); nothing you type is sent anywhere.

Data: the Lahman Baseball Database (SABR, CC BY-SA 3.0): hitters with 400+ at-bats and pitchers with 100+ innings in a season.
