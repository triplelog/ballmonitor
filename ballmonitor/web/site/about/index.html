About Ball Monitor

Ball Monitor is a collection of sports forecasts, searchable game logs, interactive baseball charts, and baseball games. Here you'll find college football playoff odds and recruiting rankings, Major League Table Tennis standings and player values, game-by-game big-league batting and pitching and NFL quarterback tables, custom charts, and four games: Triple Play, Lineup, 27K, and Home Turf.

How the forecasts work

Every forecast comes from a straightforward, open model with formulas and settings you can read and change. Each page includes a short "How this works" summary at the bottom, along with a link to inspect the full math, parameters, and limitations.

All numbers are precomputed when the site rebuilds (daily during each sport's season) so pages load fast. You can see the last rebuild date in the footer.

Data sources

The numbers on this site come from a few main places:

  • College football: ESPN for FPI ratings and schedules, and On3 for recruiting offers and consensus rankings.
  • Table tennis: Major League Table Tennis (mltt.com) for match results and SPINDEX player ratings.
  • Baseball: Retrosheet for game-by-game box scores, and the Lahman Baseball Database (SABR, CC BY-SA 3.0) for season stats.
  • Pro football: nflverse (CC BY 4.0) for NFL quarterback game logs.

Each page and table also lists its own data source.

Not betting advice

Everything here is built for fun and curiosity. Models miss things and data can be wrong, so please don't treat these numbers as betting, financial, or any other advice.
