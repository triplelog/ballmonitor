# DAD — does first-half DAD predict the second half?

_Generated by `python -m ballmonitor.models.dad.research`. Do not edit by hand._

## Claim tested

Summed over a schedule, DAD is meant to measure how well a team played given who it
played and where. If that is true, a team's first-half **DAD per game** should
predict its second half better than its first-half **win%** or **raw point
differential**. The strongest simple benchmark is the team's first-half
**adjusted margin** (least-squares margin rating, the same ratings DAD uses for
opponents), so it is reported too.

  First-half opponent ratings use only first-half games (ridge = 1 phantom 0-margin game per team, fixed before looking at results).
* Development seasons: <= 2020. Test seasons: > 2020 (63 league-seasons, **5855 team-seasons**).
  Each predictor is mapped to the target by OLS fitted on all earlier seasons of
  the same league (walk-forward), so nothing from the scored season is used.
* Team-seasons in one league-season share games and are not independent; the
  intervals below bootstrap whole league-seasons.
* Targets: second-half win% (draw = 1/2), margin per game, and schedule-adjusted
  margin per game (margin + opponent's first-half rating − home edge).

## Caveats

* In-sample choices: the per-game cap and the SD/home-edge values were chosen on the
  development seasons (<= 2020) only; the list of configurations and the
  candidate caps were picked by the author before running the study. The ridge
  value and the median-date split were fixed a priori.
* All predictors use the same first-half games; the adjusted-margin benchmark uses
  the same opponent ratings as DAD, so DAD vs adjusted margin isolates DAD's
  nonlinear margin transform and probit standardisation.
* Season splits differ by sport: college first halves are mostly non-conference
  games, so raw second-half targets are partly about schedule strength.
* College baseball and softball are not tested (no complete public game data).
* The OLS map is fitted per league; DAD's absolute level depends on the baseline
  (the average baseline is used here; others shown for comparison).
